## 部署

把 `index.html` 丢到任意静态托管即可，无需构建、无需后端。

| 平台 | 操作 |
|---|---|
| **Netlify** | 打开 app.netlify.com/drop，把整个文件夹拖进去 |
| **Cloudflare Pages** | 新建项目 → 上传 `index.html` |
| **Vercel** | `vercel deploy` 或拖拽文件夹 |
| **GitHub Pages** | 推到仓库根目录 → Settings → Pages → 选分支 |
| **任意服务器** | 直接把 `index.html` 放进网站根目录 |
| **本地打开** | 双击 `index.html` 即可用（除 AI 辅助外全部功能） |

不需要 `npm install`，不需要打包工具，不需要 Node。

## 功能

**纯手工模式（不需要 API）**
- 11 个字段逐一对应角色卡 V2 规范的键名
- 上传头像，自动盖满 512×683 卡面
- 可选开场白，可加任意多条
- 世界书：粘贴设定文本，按空行切分条目，`【关键词】` 行指定触发词
- 一键导出 PNG 角色卡，直接拖进酒馆就能用

**AI 辅助（选填）**
- 每个字段旁的 ✨ 按钮，只写那一栏，不碰其他内容
- 可勾选是否参考已填的其他字段
- 推荐 DeepSeek 官方（见下方说明）

## 关于 API 服务商

**推荐 DeepSeek 官方**（`https://api.deepseek.com`）。

原因：部分中转站的非流式响应在浏览器里会直接断连（表现为 `Load failed`），
而各站的模型名又互不通用，很容易踩坑。DeepSeek 官方目前测试下来最稳。

各站模型名对照（不通用，写错会报 400）：

| 站点 | 可用模型名 |
|---|---|
| DeepSeek 官方 | `deepseek-chat`、`deepseek-flash`、`deepseek-v4-pro` |
| 联合api | 这是个较小的中转，不过价格便宜模型各种的也都有，站点https://lhapi.gasai.cc/
接口地址进qq群获取。
页面已内置自动纠正：切换服务商时会把模型名改成该站的叫法，并提示改了什么。

不确定该用哪个模型名时，点 **「📋 拉取模型」**，会列出这把 key 真正能用的模型。

## 隐私

- 页面不向任何服务器发送你填的内容
- API Key 只存在浏览器 localStorage 里
- 打包（PNG 编码）全程在本地完成，不联网
- 只有你主动点 ✨ 时才会向你自己填的接口发请求

## 使用须知

- 导出的 PNG 同时是「图片」和「角色卡」，换头像不会丢设定，改设定不会换头像
- 卡数据存在 PNG 的 `tEXt/chara` 块里，格式为 base64 编码的 JSON（chara_card_v2）
- 世界书解析器只做文本切分，不增删改任何一个字
